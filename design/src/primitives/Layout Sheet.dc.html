Components · Box, Stack, Grid

Three primitives that hold the rhythm so nothing else has to

Box gives padding, Stack gives a gap along one axis, Grid gives columns and a gap. All three take a step from the Foundations scale and nothing else — there is no way to pass a pixel value, which is what keeps a page built from them in tune with every other page.
