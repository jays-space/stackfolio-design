Disabled vs read-only
The two are told apart by shape, not tint: read-only loses the box and keeps its contrast, disabled keeps the box and loses it. The word read only sits in the trailing slot as text, not as a glyph.
05

Label, helper, error

The label is always there and always a real <label for>. Helper is the standing instruction; error replaces it, so the line beneath a field never doubles in height when validation fires.
{{ c.name }} {{ c.body }}
Validation · live
Validation runs on submit, not on keystroke. The error takes the helper's place, the field gains aria-invalid and points at the message with aria-describedby, and the message is a live region — a screen reader hears it without moving. The message says what to do, not that something is wrong: “Give the case a title” rather than “Invalid input”. It clears as soon as the field has a value again.
