The underline is the link; colour only says which one

Link is the only navigating element that keeps the type of the sentence around it. It sets no size of its own inline, takes colour from the Foundations text roles, and carries an underline in every state — including disabled — so the target is never identified by hue alone.

03

Standalone

Out of a sentence, the link sets its own type — body-sm at weight 600 — and takes vertical padding so a row of them clears the minimum hit target. It is still a link, not a button: it navigates and nothing else.
