Anatomy

02

Variants × sizes

Emphasis descends by subtraction: fill, then low fill, then hairline, then nothing. One primary per view. Every specimen is live — hover, tab to and hold it.
sm · 28 md · 36 default lg · 44 icon-only primaryThe one action the view exists for. secondaryA real alternative, on a working surface. outlineAvailable but not urged. Hairline only, no fill. ghostDismiss, cancel, toolbar actions. No box until hover. cautionDestructive. Fills only under the finger.
Why caution is not filled The primary accent is already oxblood. A filled red destructive button would read as the ordinary primary action at a glance, which is the opposite of what a destructive control has to do. Caution therefore states itself with a hairline and a label, and takes a fill only on press — the moment the action is actually committed.
Pairing A committal pair is primary plus ghost, in that order, with --space-3 between them. Two filled buttons side by side is drift.
03

Six states, every variant

Held open, not hovered for. Each specimen below is pinned to one state so the whole matrix can be compared at once.
default hover focus pressed disabled loading primary secondary outline ghost caution link
Hover A value changes and nothing moves: the fill steps deeper, or a wash and a warmer border arrive. Size and position are identical to default. accent-deep · accent-quiet · confirm · dur-quick
Focus The one ring, additive: it appears on top of whatever else the button is doing and is never traded for a colour change. Keyboard only — a pointer press does not draw it. outline 2px focus-ring · offset 2px
Pressed One pixel down into the surface, and the deepest step of the variant's colour. Caution is the only variant that gains a fill here. translateY(1px) · accent-deep · caution-deep
Disabled The whole control at op-disabled, never the label alone, and the layout does not change. A disabled button always has the reason stated next to it — the state says no, the sentence says why. op-disabled 0.38 · cursor not-allowed · disabled attr
Loading No spinner. The label is replaced by what is happening and breathes on the same 1.4s cycle placeholders use; the box keeps its own width, so nothing beside it shifts. aria-busy · btnBreathe 1.4s ease-settle
Rationale is required before a verdict can be filed.
04

Icon configurations

Leading icons name the action; trailing icons name where it goes. A button carries at most two, and never the same one twice.
Leading
The default position. Use for creation, state change and anything with a settled mark.
Trailing
Direction, disclosure and external destinations only. Not decoration.
Both
Allowed when the action and its destination are both worth stating. Rare by design.
Icon-only
Square box, no padding, name carried in aria-label. Only for actions a reviewer already knows by shape.
Icon sizing The icon steps with the button and never on its own: --icon-2 at sm, --icon-3 at md, --icon-4 at lg, drawn in currentColor so it inherits every state change for free.
05

Link-styled navigation

Two separate axes: what the control looks like, and what element it is. Appearance follows emphasis; the element follows behaviour — anything that changes the address is an anchor.
Link appearance
Body type, --confirm, a 1px underline at 40% and no box. Identical to prose links, so an inline action inside a paragraph never invents a second look. It is the lowest emphasis the component offers.
Button appearance, anchor element
Same geometry, same states, same ring — rendered as <a href>, so it opens in a new tab, is copyable and is announced as a link. Never a <div onclick> and never a button that navigates.
06

Accessibility

Keyboard focus is never removed 2px --focus-ring at a 2px offset, on every variant and every surface, drawn on top of hover rather than instead of it. Ghost and link keep it even though they have no box.
Disabled is not colour alone The native disabled attribute carries it to assistive technology; opacity and cursor carry it visually; a sentence beside the control carries the reason. Anchors use aria-disabled instead, since a link cannot be disabled.
Icon-only buttons are named Every icon-only instance takes an aria-label; the mark itself is aria-hidden. A labelled button never gets one, so its visible text and its announced name stay the same words.
Targets meet the 44px floor lg is --hit-min on its own. sm and md are only permitted where the container supplies the rest of the target — a 44px row, a toolbar, a list item.
Loading is announced, not just animated aria-busy plus a label that names the work in progress. The breathing opacity is decoration on top of a change of words.

What Button added to the foundation

Three roles were missing and are now on the Foundations sheet, marked new. Every other value here already existed.
--control-h-sm / -md / -lg 28 / 36 / 44. Shared with fields and selects so a control row aligns without nudging.
--hit-min 44px. The pointer-target floor, stated once so no component argues it down.
--caution / -deep / -quiet Borrowed from the reject verdict rather than adding a hue, so red means one thing across the product.
Not in Button No pill radius, no gradient, no shadow, no full-width variant, no size below 28px, and no second filled variant. Split buttons, menu buttons and toggle groups are separate components that compose this one.
