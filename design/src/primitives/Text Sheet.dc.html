Component · Text

Eleven roles, and the element is a separate question

Text is the only component permitted to set a font size. It carries the Foundations scale as named roles and nothing else: a role picks family, size, line height, weight, tracking and a default colour together, and the HTML element is chosen independently for document structure.

The role is the look; the element is the document. Both columns below are the same role on four different elements, and the rendering is identical.

Do Pick the element from the outline of the page — one h1 per screen, then h2, h3 with no level skipped — and pick the role from how loud the line should be. A card title that is fourth in the outline is element h4, role h5.
Don't Don't reach for a heading element to get a bigger size, and don't demote a real heading to a span to make it quieter. Both are available as roles, and a screen reader reads the element.
