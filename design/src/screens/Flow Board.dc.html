One case study, three lanes, one loop

Every box is a screen that exists. Solid arrows are the happy path. The rules under each box are the ones the screen enforces — not decoration, the actual gates.

Happy path Branch Unhappy path Not yet built
Lane C — Author Jay · draft → submit → deferred → revise → approved
Draft editor Compose the case Problem and solution design are required. A build is optional. A level marked not-buildable needs a stated reason. Blank is a gap; stated is a deliverable.
declare
Niche · toolset · visibility Submit, or be blocked Niche is the routing key. The toolset you chose is part of the claim. No problem, design, toolset or speciality → blocked with a specific reason. Visibility ≠ routing.
push
Thread · under review Locked, comments closed Track and reactions only. The author cannot edit while judgment is pending. One bit decides it: review concluded, yes or no.
defer
Revision editor Amend → v2 The defer sits at the top with what must change. What you changed is captured for the lineage. Budget 1. Loop re-fires to the same reviewers plus any newly eligible.
re-review
Thread · concluded Approved after revision Aggregate tally, attributed verdicts, endorse primitive, comments reopened. v1 is not deleted. The trajectory is the teaching content.
unhappy paths
Awaiting eligible reviewers Under quota. A curator is notified — it does not stall silently.
Rejected · terminal Budget spent and still deferred. Not published; the trajectory stays readable.
Autosave failed Explicit “not saved” warning, never silent loss. Not yet built.
Lane — Reviewer @nkosi.dev · summoned → judges → the round closes
Review queue Push, not browse The case declared a niche; the system routed it. No open-cases wall exists. Same for open and private reviews. Discovery never routes through visibility.
open
Verdict panel · clarify Ask, without judging Open, repeatable, editable. Stays on the reading surface. MVP may fold this into the thread — it is one deletion, not a redesign.
commit
Verdict panel · cast The committal act Value + required rationale, on the whole case. The panel sinks — reading becomes judging. Casting closes the round. No edits after.
tally
Aggregate N independent verdicts Not a shared thread. Each verdict is attributed and stands alone. Resolution is a counting rule in config. The screen renders it, never decides it.
Lane B — Participant @r.dlamini · signs in → reads → tracks → comments when it concludes
Sign in Members only Auth.js + Cognito. Members are handpicked, so there is no anonymous tier. Reading is a member act. The gate is at the door, not around each action.
browse
Case reader Read the case whole Problem, design, toolset, alternatives, falsifier, then any build. One read, no tabs. Outcome and tally sit in the rail. The verdicts are on the same page, further down.
track
Thread · under review Watch, don't speak Track and emoji only. Comments closed to everyone, not just to you. Earned reverence for the process — the gate is what makes passing mean something.
concludes
Comments + endorse Speak, and endorse General comments reopen. A review can be endorsed with a reason, rescindably. Primitive in, ranking out. No count, no score, no leaderboard.
Still undrawn Quoting a passage inside a rationale, so a whole-case verdict can still point precisely. Endorsement reasons on hover. Neither changes the loop; the first would sharpen every defer.
